Épreuve blanche commentée

Les 25 questions d'une épreuve blanche passée en conditions réelles, réécrites avec nos propres exemples : mêmes notions, mêmes pièges, mêmes formats. Essaie de répondre avant d'ouvrir la solution.

  • Formats rencontrés : QCM (4 ou 5 propositions, parfois des images), Vrai / Faux en tableau, listes déroulantes, glisser-déposer, relier, zones de code à cliquer, et exercices de code dans 3 éditeurs (HTML / CSS / JS) avec des fichiers verrouillés.
  • Questions de documentation : un navigateur est fourni et le temps est limité (5 min). Cherche « nom de la notion + mdn » et lis le premier exemple de code.
  • Exercices de code : 4 à 5 min chacun. Utilise « Essayer » autant que tu veux, mais valide avant la fin du temps : une correction non validée vaut 0.
  • Pas de retour en arrière. Le niveau des questions s'adapte à tes réponses.

Ces questions sont des adaptations écrites pour la formation, pas les questions officielles.

3JavaScriptDocumentation · listes déroulantes · 5 min

Une page affiche la position de l'utilisateur sur une carte (Leaflet ou Google Maps).

a) Quelle fonction récupère la position GPS de l'utilisateur ? (choix : getLocalisation, getCurrentPosition, getGPS…)

b) Comment ajoute-t-on un marqueur sur la carte ? (choix : setMarker, addMarker, Marker…)

Voir la solution

a) getCurrentPosition() · b) on crée un marqueur (Marker / L.marker) et on l'ajoute à la carte

navigator.geolocation.getCurrentPosition((pos) => {
  const { latitude, longitude } = pos.coords;
  L.marker([latitude, longitude]).addTo(carte);           // Leaflet
  // new google.maps.Marker({ position: { lat: latitude, lng: longitude }, map: carte });  // Google Maps
});

Piège : la position vient du navigateur (navigator.geolocation), pas de la bibliothèque de carte. Les noms qui « sonnent juste » (getLocalisation, setMarker) n'existent pas.

6JavaScriptCode · tableau de tests

La fonction doit renvoyer la somme des prix. L'aperçu affiche un tableau de tests : totalPanier([10]) → NaN, totalPanier([]) → NaN. Trouve le bug.

function totalPanier(prix) {
  let total = 0;
  for (let i = 0; i <= prix.length; i++) {
    total += prix[i];
  }
  return total;
}
Voir la solution

i < prix.length au lieu de i <= prix.length

Avec <=, la boucle lit prix[prix.length], qui vaut undefined, et nombre + undefined donne NaN. Même un tableau vide fait un tour de boucle. (Avec des chaînes, on obtiendrait "…undefined" à la fin.)

Raisonne à partir des sorties : quand tous les résultats ont le même défaut, cherche une erreur commune (ici, un tour de trop).

13JavaScriptQCM

Que fait ce code ?

document.addEventListener("keydown", afficher);

function afficher() {
  console.log("touche !");
}
  1. Il affiche « keydown » à chaque touche
  2. Il enregistre un écouteur qui appellera afficher() à chaque touche pressée
  3. Il ajoute deux écouteurs : « keydown » et « touche ! »
  4. Erreur : afficher est déclarée après son utilisation
Voir la solution

B

On passe la fonction (afficher, sans parenthèses) : elle sera appelée plus tard, à chaque événement. Avec afficher(), elle s'exécuterait tout de suite, une seule fois. Une déclaration function est utilisable avant sa ligne (hoisting).

15JavaScriptQCM

Que fait ce code (on suppose que chargement est une promesse et que les fonctions existent) ?

chargement
  .then(lireJson)
  .then(filtrer)
  .then(afficher)
  .catch(signalerErreur);
  1. Il crée 3 promesses de réussite et 1 d'échec
  2. Il enchaîne plusieurs promesses
  3. Il échoue toujours, car catch est à la fin
  4. Il ne fonctionne pas
Voir la solution

B

.then() renvoie une nouvelle promesse : chaque étape reçoit le résultat de la précédente. Un seul .catch() en fin de chaîne intercepte une erreur à n'importe quelle étape ; il ne s'exécute qu'en cas d'erreur.

fetch("produits.json")
  .then((rep) => rep.json())
  .then((produits) => console.log(produits))
  .catch((err) => console.error(err));

22HTMLQCM en images

Quelle image correspond à ce SVG ?

<svg width="120" height="120">
  <rect width="120" height="120" fill="navy" />
  <circle cx="60" cy="60" r="30" fill="gold" stroke="white" stroke-width="4" />
</svg>
Voir la solution

B — un cercle doré de 60 de diamètre, centré

r est le rayon : 30, donc un diamètre de 60, soit la moitié du carré. A confond rayon et diamètre, C oublie cx/cy (centre en 0,0), D inverse fill et stroke.

24JavaScriptQCM

Quel est le résultat de "2" + 3 + 4 ?

  1. 9
  2. "234"
  3. "27"
  4. 234
Voir la solution

B — "234"

De gauche à droite : "2" + 3 = "23" (concaténation), puis "23" + 4 = "234". À l'inverse, 2 + 3 + "4" donne "54".
